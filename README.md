# ABYSSAL — Descend to the Floor of the Ocean

A cinematic, scroll-driven website for ABYSSAL, a fictional deep-sea
expedition company that takes eight civilians a year to the ocean floor
aboard its submersible, the **EREBUS**. Scrolling down *is* diving down:
the depth runs 0 m → 3,800 m across five ocean zones, with a live HUD
depth meter, per-zone facts, spec callouts, pricing, and a "Join the
Manifest" CTA.

## Visuals: real AI-generated footage, scroll-scrubbed as a frame sequence

Five real 10-second video clips (Surface, Sunlit, Twilight, Midnight, The
Floor — 50s total) were generated by the user and dropped in. Each clip is
extracted at 10fps and packed into 640×360 sprite sheets (`public/frames/`,
`src/frames.js`); `src/frameSequence.js` draws the frame matching the
current scroll position onto a full-bleed `<canvas>`, cover-fit cropped to
the viewport. Scroll progress within each pinned `.zone-section` maps
directly to a frame index within that scene.

The five clips were generated independently rather than frame-chained
(start-image → end-image), so they don't join pixel-for-pixel and the
EREBUS's design isn't perfectly consistent between them. Rather than
pretend it's one unbroken take, each zone boundary gets a short
cross-dissolve (~7% of that zone's scroll range) from the previous scene's
final frame into the new one — it reads as an intentional cut, not a glitch.

An earlier version of this project used a procedural Three.js/WebGL scene
in place of real footage (the original brief specified Seedance 2.0 via
the Higgsfield MCP, which wasn't available in the build environment). That
approach is no longer used now that real footage exists, but the git
history keeps it if useful as a fallback with no video-asset dependency.

## Run it

```bash
npm install
npm run dev
```

Then open the printed `http://localhost:5173/` URL and scroll.

## Structure

- `src/main.js` — scroll → depth mapping, HUD, section reveals, manifest form
- `src/frameSequence.js` — canvas frame-sequence renderer + zone-boundary
  cross-dissolve
- `src/frames.js` — sprite-sheet layout metadata (frame count, grid, tile size)
- `src/scene/zones.js` — single source of truth for depth breakpoints and
  zone labels
- `public/frames/<zone>/sheet_0N.jpg` — the sprite sheets themselves (100
  frames per zone, packed 5×4 per sheet)
- `src/style.css` — HUD, pinned sections, responsive layout
- `index.html` — page structure: hero, per-zone fact cards, spec
  callouts, pricing, manifest CTA
